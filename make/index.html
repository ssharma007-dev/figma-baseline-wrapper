Figma baseline link maker

Turns a Figma frame into one link for Applitools Autonomous. The link shows the design at actual size and carries the design's elements (positions, sizes, text, colours) as DOM. Choose a Figma image, or text drawn by the browser to compare text.

Baseline link for Autonomous
Check before you use it:
    1. In Autonomous, set the viewport to (the Figma frame size). The width must match exactly. The height can be smaller; the rest of the design scrolls and full-page capture still gets all of it.
    2. Run 1: open this link and take a full-page visual checkpoint. It becomes the baseline.
    3. Run 2: change only the URL to the live website page and run again.

    Privacy and safety

    • We store nothing. This is a static page with no server or database behind it. Your Figma link, token and design never reach us.
    • Your token goes only to Figma (api.figma.com, over HTTPS), directly from this browser. It is never added to the baseline link.
    • "Remember the token" keeps it only in this browser on this computer. Leave it unticked on shared or public computers.
    • Use a trusted device and network. Avoid shared computers, and prefer your work network or VPN over public Wi-Fi.
    • Treat the baseline link like the design itself. Anyone with the link can see the design image and its text for about 30 days. Share it only with people who can see the Figma file.
    • Use a limited token: only the file_content:read scope, with a short expiry. Revoke it in Figma (Settings → Security) when you no longer need it.
