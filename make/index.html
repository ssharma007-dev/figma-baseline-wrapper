Figma baseline link maker

Turns a Figma frame into one link for Applitools Autonomous. The link shows the design at actual size and carries the design's elements (positions, sizes, text, colours) as DOM.

Baseline link for Autonomous
  1. In Autonomous, set the viewport width to px (the frame width).
  2. Run 1: open this link and take a full-page visual checkpoint. It becomes the baseline.
  3. Run 2: change only the URL to the live website page and run again.

Your token is sent only to Figma (api.figma.com), directly from this browser. It is never added to the link.
